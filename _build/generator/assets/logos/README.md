# Ressources — Logos de sociétés

Placer ici les logos aux formats **PNG** ou **JPEG** des sociétés fictives.

Les logos ne sont pas encore utilisés par les générateurs (utilisation de bandeaux colorés à la place).
Ils pourront être intégrés dans une future version via `reportlab.platypus.Image`.

## Convention de nommage
```
logo_<slug>.png   # ex. logo_acme.png
```
